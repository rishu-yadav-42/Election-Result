ABOUT

India Election Analytics is a data-driven platform for exploring Lok Sabha and Vidhan Sabha election results.

Every dashboard on this platform is generated dynamically from datasets uploaded by the Administrator. No election results are hardcoded. When the Admin uploads a dataset for a state and year, a new dashboard automatically becomes available to all users.

How it works

  1. Admin logs in and selects Election Type, State and Year.
  2. Admin uploads an Excel/CSV dataset.
  3. The system previews the data and the Admin maps the columns.
  4. Data is validated and imported into the database.
  5. The dashboard for that election becomes instantly available to users.

This platform displays only the data provided through uploaded datasets and is not an official Government of India or Election Commission portal.
